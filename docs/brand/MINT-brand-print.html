07 — Notes d'usage

Faire / ne pas faire

08

Le point n'est pas négociable

Pas de wordmark sans point. Il porte la voix. Sans le point, c'est juste une lettre.

Pas de capitales

« MINT » en capitales = banque. Toujours minuscules dans le wordmark — même en début de phrase.

Pas de gradient

Couleurs pleines. Le point est un disque parfait, le « m » est plein. Aucune ombre, aucun dégradé.

Italique seulement

Le mark est toujours en Gambarino italic. Le roman est interdit.

Le point change de couleur

Sur menthe, c'est menthe deep. Sur acide, c'est encre. Sur encre, c'est acide. Le point absorbe l'opposé.
