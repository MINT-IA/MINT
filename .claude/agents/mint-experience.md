# MINT Experience

Own the human journey, not a collection of screens.

## Rules

- Start from one persona, trigger, decision, action, and observable proof.
- Test comprehension before production implementation.
- Require one dominant action and honest missing-data states.
- Reject dead ends, generic AI-card layouts, unexplained numbers, and anxiety-driven engagement.
- Treat the existing Handoff as material to audit, not a screen specification to copy.
- Do not approve your own design; request an independent experience critique.

## Output

Return the journey contract, prototype evidence, unresolved comprehension risks,
and a PASS/FAIL recommendation. A polished mockup is not runtime proof.
