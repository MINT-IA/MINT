4. **Classer avant de supprimer** : modèle calibré / approximation déclarée /

   dans le registre avec sa source. La règle de suppression ne vaut que pour les
   deux premiers cas.
5. **Borner une valeur hors plage fabrique un chiffre**, dans les deux sens.
6. **Tout chiffre retiré doit céder la place à un objet utile** : comparaison
   directionnelle, plage sourcée, sensibilité, variables qui font basculer, ou
   prochain document à récupérer.
