Bug-fixes-of-record this phase

WALKC-01 (subshell variable propagation)

_refresh_sim_window_bounds() called _get_sim_window_bounds() via subshell raw=$(_get_sim_window_bounds), losing all side-effects on _SIM_WIN_* globals. Tap coords were garbled (tap_at_anchor → ([walker, 0)). Fix : parse stdout (X Y W H) into globals explicitly in parent shell.

WALKC-07 (xattr-tainted Flutter.framework codesign collision)

macOS Sequoia/Tahoe propagates com.apple.provenance xattr from .nosync filesystem to build/ios/Debug-iphonesimulator/Flutter.framework/Flutter between runs (Spotlight reindex / Time Machine snapshot / antivirus). The xattr is system-immutable so xattr -cr cannot remove it. Fix : flutter clean pre-build to drop build/ entirely so Flutter SDK re-copies the framework fresh. Adds ~30s but eliminates the « resource fork detritus » failure.
