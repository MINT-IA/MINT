**tools/checks/maestro_no_e2e_defines.py** (~25 LOC):
```python
#!/usr/bin/env python3
# Lint: ship-gate Maestro flows must NOT reference dev-only defines.
# Per ROADMAP :190 SHIP-01 acceptance criterion: "NO MINT_E2E_* defines".
import pathlib, re, sys

FORBIDDEN = re.compile(r'(MINT_E2E_|MINT_DISABLE_BETA_MODAL|MINT_FORCE_)')
ROOT = pathlib.Path(__file__).resolve().parents[2] / 'apps/mobile/.maestro'

def main() -> int:
    if not ROOT.is_dir():
        print(f"::error::ship-gate Maestro dir missing: {ROOT}", file=sys.stderr)
        return 1
    hits: list[str] = []
    for yaml in ROOT.rglob('*.yaml'):
        for i, line in enumerate(yaml.read_text(encoding='utf-8').splitlines(), 1):
            if FORBIDDEN.search(line):
                hits.append(f"{yaml.relative_to(ROOT.parent.parent.parent)}:{i}: {line.strip()}")
    if hits:
        print("::error::ship-gate flows reference dev-only defines (forbidden by SHIP-01):", file=sys.stderr)
        for h in hits:
            print(f"  {h}", file=sys.stderr)
        return 1
    print(f"OK — {sum(1 for _ in ROOT.rglob('*.yaml'))} ship-gate flows clean of MINT_E2E_* defines.")
    return 0

if __name__ == '__main__':
    sys.exit(main())
```

**tools/simulator/maestro_ship_gate.sh** (~120 LOC, bash strict mode):

Inputs: `--device <iphone-17-pro|iphone-se|ipad-mini|all>`, `--ipa-path <path>` (optional — default: rebuild via `flutter build ios --release`), `--api-url <url>` (default: `https://mint-staging.up.railway.app/api/v1`).

Logic per device:
1. Resolve sim UDID by device name via `xcrun simctl list devices --json | jq` (fail-closed if not found — print actionable message).
2. `xcrun simctl boot <udid>` (idempotent — `|| true` if already booted).
3. `xcrun simctl install <udid> <ipa-or-app-path>`.
4. For each ship-gate flow in `apps/mobile/.maestro/*.yaml` (sorted lexicographically — 00, 01, ..., 08, then phase-specific in name order):
   - `maestro --device <udid> test apps/mobile/.maestro/<flow>` with 5-min timeout.
   - Capture exit code into a tally `flow_results[<flow>]=<pass|fail>`.
5. `xcrun simctl shutdown <udid>` at the end.
6. Write `.planning/phases/97-mvp-ship-gate/maestro-runs/<device>-<timestamp>.json` with the tally.
7. Exit 0 only if ALL flows pass; exit 1 with a summary if any fail.

If `--device all`: run sequentially against all 3 devices, aggregate tally to `.planning/phases/97-mvp-ship-gate/maestro-runs/all-<timestamp>.json`. Total green target: 13 × 3 = 39 (NOT the ROADMAP's 8 × 3 = 24 — we add 4 phase-specific flows but only require them green on iPhone 17 Pro at minimum; the script flags them as soft-required for SE/iPad mini — this is a Karpathy #2 simplicity call, document explicitly).
