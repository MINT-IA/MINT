```dart
static CoachProfileSeed? byArchetype(String archetypeSlug) {
  switch (archetypeSlug) {
    case 'expat_us':
      return registry['julien_expat_us'];
    case 'swiss_native':
      return registry['julien_swiss'];
    default:
      return null;
  }
}
```

**Codex C3 MEDIUM contract (REVIEWS.md 2026-05-22):** the dart-define value passed by the walker (`--dart-define=MINT_E2E_ARCHETYPE=<slug>`) is the archetype SLUG (e.g. `expat_us`), but the registry key is the SEED NAME (e.g. `julien_expat_us`). Without this helper, the walker's slug would not resolve and the gate test would silently run against an empty profile. The helper makes the mapping explicit and the unit test (`by_archetype_expat_us_returns_julien_expat_us_seed`) is the deterministic exit gate.

1. **Extended `CoachProfileSeed` (not `CoachProfile`) with the new fields.** The PLAN.md example code referenced `CoachProfile(firstName: 'Julien', age: 38, canton: 'GE', archetype: 'expat_us', nationality: 'US', usTaxPerson: true, ...)` — but the registry holds `CoachProfileSeed` (the 6-field pinned class at `coach_profile_seeds.dart:28-96`), not `CoachProfile` (the 1900-line model at `models/coach_profile.dart`). 3. **No default arm in `byArchetype()`.** Unknown slug returns null. The walker / Maestro flow / test caller MUST handle null explicitly. This is the Codex C3 contract behavior — it surfaces typos at the boundary instead of silently routing to no seed.

4. **REFACTOR phase skipped.** GREEN implementation is minimal (additive const fields + 1 seed entry + 1 switch helper). No code cleanup warranted per TDD doctrine. The next plan (Wave 03 Maestro flow) is the place where the seed actually exercises the gate end-to-end.
