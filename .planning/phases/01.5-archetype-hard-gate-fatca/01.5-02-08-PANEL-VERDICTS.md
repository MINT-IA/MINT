### 6. accessibility-expert (wshobson) — BLOCK (4 HIGH WCAG 2.1 AA findings)

**Engram obs #313.** Verdict **BLOCK**.

**Top finding:**
> This is the primary compliance-driven gate (FATCA / LSFin scope-out) that any non-swissNative archetype hits. Screen-reader users hitting this flow today (a) cannot identify the email input by name, (b) get no audible cue when their email fails validation, (c) get no audible cue when the coach silently redirects them to /waitlist, and (d) cannot tell Yes/No are a binary radio group. The flow ships a compliance promise that excludes users with assistive tech — backwards.

**Findings (4 HIGH + 1 MEDIUM):**

1. **[HIGH WCAG 1.3.1 / 4.1.2]** MintTextField label not programmatically associated — `waitlist_form.dart:2017-2022` + root cause at `mint_text_field.dart:61-83` (InputDecoration.labelText not set; label rendered as sibling Text widget). Screen readers don't announce the email input's name.
   - **Phase status:** PRE-EXISTING — root cause is in MintTextField, a shared widget. This phase surfaces but does not cause. Recommend dedicated a11y phase OR address in 01.6.

2. **[HIGH WCAG 3.3.1 / 4.1.3]** Error text inserted with no SemanticsService.announce — `waitlist_form.dart:2038-2044`. Only success case has announce (`waitlist_success.dart:2111`). Email validation failure + network error silent for screen reader users.
   - **Phase status:** PHASE-INTRODUCED by 02-02.

3. **[HIGH WCAG 1.3.2 / 4.1.3]** Gate-redirect via `context.go` silent — `coach_chat_screen.dart:1437-1445`. No post-frame announce of new screen. User opens coach, gets silently redirected to /waitlist with no audible feedback.
   - **Phase status:** PHASE-INTRODUCED by 02-03.

4. **[HIGH WCAG 1.3.1 / 4.1.2]** Yes/No FilledButtons lack radio group container Semantics + position-in-group hint — `us_tax_person_screen.dart:1779-1811`. Screen reader announces two unrelated buttons instead of a binary radio group.
   - **Phase status:** PHASE-INTRODUCED by 02-03.

5. **[MEDIUM]** `_UsTaxPersonStep` has no PopScope / WillPopScope — `onboarding_shell_screen.dart:1601-1633`. Back-gesture pops entire onboarding instead of stepping back to intents.
   - **Phase status:** PHASE-INTRODUCED by 02-03.
