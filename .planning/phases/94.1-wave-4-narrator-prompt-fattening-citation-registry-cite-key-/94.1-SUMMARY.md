# Phase 94.1 Plan 01: Narrator-Prompt Fattening Summary

**One-liner:** Closed-world citation-grammar fragment fattens the narrator system prompt with the 18-key registry vocabulary + placement rules ; lifts Sonnet gate-correct from 6% to 20% and Haiku from 14% to 20% on the unchanged 50-fixture pack — meaningful improvement, but Stage 3 thresholds (95% / 90%) remain NOT MET.

## Objective recap

Phase 94 close-out landed at NO-GO + PARTIAL on the flag flip because the Stage 3 gates failed by huge margins (Sonnet 6%, Haiku 14%, latency +56%). The root cause was mechanical : the narrator system prompt did not teach the `{{cite:<key>}}` placeholder syntax. Phase 94.1 added that teaching as a flag-conditional appendix to both narrator paths and re-ran the eval.

## What was built

1. **Source of truth** — `app/services/coach/citation_grammar.py` exports `CITATION_GRAMMAR_FRAGMENT: str`, built at module import from `CITATION_REGISTRY` (18 keys, sorted alphabetically for determinism). The fragment has 4 sections : opening cardinal rule, 18-key vocabulary list with FR descriptions, 3 verbatim examples (cited / no-key fallback / rejected), placement rules.

2. **Bundle integration** — `app/services/coach/bundles/citation_grammar.py` wraps the fragment as `CitationGrammarBundle(BundleBase)` (Pydantic v2 frozen). The bundle is registered per-call inside `compile_bundles` (NOT in the `_ALWAYS_ON` constant) when `settings.COACH_CITATION_GATE_ENABLED=True`. Preserves the canonical 2-bundle always-on list when the flag is OFF.

3. **Legacy integration** — `build_narrator_system_prompt` reads env var `COACH_CITATION_GATE_ENABLED` (deferred-import pattern, avoids circular import via `app.core.config`) AND the live `settings` attribute. When True, appends the fragment with `\n\n---\n\n` separator. When False, output is byte-identical to the pre-94.1 snapshots (5×2 byte-identity tests still green).

4. **Eval harness propagation** — `tools/eval_narrator.py` `--gate=on` now sets `COACH_CITATION_GATE_ENABLED=true` on both env var and live settings for the duration of the run, then restores the original value at exit. Without this, the LLM would not see the fattened prompt and `--gate=on` would measure the unchanged baseline.

5. **12 new tests** — `tests/test_citation_gate/test_narrator_grammar_fragment.py` covers fragment importability, 18-key coupling, verbatim examples, no new `{slot}` placeholders, builder purity, legacy-path flag-on / flag-off byte-identity, bundle-path flag-on / flag-off, compiled-bundles dedup, CitationGrammarBundle Pydantic invariants. All 12 green.

6. **Documentation** — `94.1-01-PLAN.md` (Path C architectural decision + risk register + interpretation rules), `94.1-EVAL-DELTA.md` (full pre/post comparison + per-category × verdict matrix + scoring contract caveat + 94.2 hypotheses), `94-03-FLAG-FLIP-PROPOSAL.md` patched with Post-94.1 measurement section.
