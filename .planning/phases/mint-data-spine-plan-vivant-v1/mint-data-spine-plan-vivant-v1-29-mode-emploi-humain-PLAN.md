# Plan 29 — Mode d'emploi humain

## Objectif

Documenter comment MINT doit fonctionner pour un utilisateur humain, avec le chat comme navigateur de lucidité financière au-dessus de la situation, du budget, des trois piliers, des projections et des plans.

## Portée

- Créer un document produit lisible par humain et par agent.
- Décrire le parcours naturel de l'utilisateur.
- Fixer les écrans centraux et les données centrales.
- Donner un critère de fonctionnement vérifiable par Maestro.

## Hors portée

- Pas de refonte UI dans ce plan.
- Pas de nouveau modèle de données.
- Pas de changement backend.

## Vérification

- Le document doit vivre dans `.planning/product/`.
- Le wiki lint doit accepter le fichier.
- Les textes doivent respecter les règles françaises et LSFin.
