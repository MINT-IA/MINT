<objective>
Block 3a / PFIC / treaty advice from being LLM-generated for `expat_us` users — instead, surface a FATCA hand-off card pointing to a US-CH cross-border specialist.

Purpose: today, an expat_us user typing « j'ai 70k de 3a, je dois faire quoi? » triggers a generic 3a impératif from `claude_coach_service.py` with no FATCA reference. The existing `doctrine_checks.py:291` post-validation rule + `fallback_templates.fatca_fbar_guidance` are advisory only — they never gate the LLM call. Phase 93 closes this by adding a **pre-emission gate** so the LLM is never called for this archetype × topic combo. The user sees a hand-off card with FATCA + FBAR + PFIC + CH-US treaty context and a clear CTA: « Prends rendez-vous avec un·e spécialiste US-CH avant tout versement 3a. »

- 1 new backend service `fatca_gate.py` with topic regex + handoff payload builder
