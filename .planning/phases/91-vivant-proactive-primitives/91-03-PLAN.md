# Phase 91 — Plan 03: Cross-Session Opener (VIVANT-02)

## Goal
Make `CoachChatScreen` never start cold for a returning user : on screen mount, if the user has seen the premier-éclairage and has prior memory, prepend a single coach bubble that references the last `CapMemory` outcome + `ConversationMemoryService` summary (Cleo 3.0 parity).

## Requirements covered
- VIVANT-02

La dernière fois, on parlait de {topic}. {action_suggestion}. » per CONTEXT.md `<decisions>` VIVANT-02 + `MVP-PLAN-2026-04-21:75-83`.

- `apps/mobile/lib/screens/coach_chat_screen.dart` (empty-state init, around the `_messages.isEmpty` branch) — **EDIT** : on `initState` / first build, when `_messages.isEmpty && hasSeenPremierEclairage`, call `buildOpener(...)`. If non-null, prepend a synthetic coach bubble (existing `ChatMessage` model with `role: assistant`, `synthetic: true` flag if model supports). If null, fall back to the existing 4-chip opener (already shipped, do not modify).

- `apps/mobile/l10n/*.arb` — **EDIT**, add ONE new key `coachOpenerCrossSessionTemplate` with placeholder « Re. La dernière fois, on parlait de {topic}. {actionSuggestion}. » across all 6 locales (FR/EN/DE/ES/IT/PT). **This is the only ARB addition this phase.**

## Steps
1. Build `cross_session_opener_builder.dart` as a pure async function. Inputs : `CapMemoryStore.lastOutcome` (nullable), `ConversationMemoryService.getSummary(maxTokens: 200)` (nullable), `CoachProfile` (for archetype-aware suggestion). Outputs : nullable formatted string. **No silent prefetch** — caller awaits on screen mount.
2. Implement topic extraction from `lastOutcome` (use the existing field name on `CapOutcome`, e.g. `lastOutcome.topic` or derive from `lastOutcome.capLabel`). Fallback : if no topic, return null.
3. Implement action suggestion : reuse `CapMemoryStore.suggestNextAction(profile)` if it exists ; else fallback to a generic « tu veux qu'on regarde la suite ? » via the new ARB key.
4. Add ARB key `coachOpenerCrossSessionTemplate` in `app_fr.arb` with `@coachOpenerCrossSessionTemplate.placeholders = {topic, actionSuggestion}`. Mirror to `app_en.arb`, `app_de.arb`, `app_it.arb`, `app_es.arb`, `app_pt.arb`. Run `flutter gen-l10n`.
5. In `coach_chat_screen.dart` empty-state init, await `buildOpener(...)` — UX rule : if it takes > 500ms, show a tiny loading shimmer (per CONTEXT.md `<decisions>` VIVANT-02 « UX feedback if it takes >500ms »).
6. If opener returns non-null, prepend a synthetic `ChatMessage(role: assistant, content: opener, synthetic: true)` to `_messages` BEFORE the 4-chip block renders. The 4-chips remain visible below.
7. If opener returns null (first-time user, no memory), keep current behaviour (4-chip opener only) — no regression.
8. Run `flutter analyze`, `flutter test`, `validate_arb_parity()` MCP, `flutter gen-l10n`.
