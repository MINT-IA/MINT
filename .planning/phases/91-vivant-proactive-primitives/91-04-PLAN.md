## Steps
1. **Audit first (Karpathy #1, no assumptions)** : grep `flutter_local_notifications` usage in `notification_service.dart` to confirm it's wired for iOS APNs simulator + has a tap callback. Confirm `_scheduleNotification(payload, scheduledAt)` API surface.
2. Build `proactive_notification_copy.dart` mapping the 6 trigger enum values → `(title, body)` localised pairs. Reuse existing onboarding / coaching ARB keys where possible. Document any new ARB key in PR body.
3. In `notification_service.dart`, implement `scheduleProactiveTriggerCheck()` :
   - Read current `CoachProfile` from provider.
   - Call `ProactiveTriggerService.evaluate(profile)`.
   - If non-null AND trigger.type ∈ {paieDay, documentUploadCompleted, confidenceImproved, jitaiFiscalDate, lifecyclePhaseChanged, inactivityReturn7d} → compute `scheduledAt` (next paie day for paieDay, immediate for documentUploadCompleted, etc.).
   - Apply quiet-hours filter : if `scheduledAt.hour ∈ [22..23] ∪ [0..7]`, push to next 09:00 user-local. If weekend AND type != confidenceImproved, skip until Monday 09:00.
   - Schedule via existing `_scheduleNotification`. Emit Sentry breadcrumb `proactive_push.delivered` (NB: « delivered » here means « scheduled to be delivered » — actual delivery confirmation comes from iOS, can refine later).
4. In `notifications_wiring_service.dart:31`, invoke `scheduleProactiveTriggerCheck()` on app boot AND on every `CoachProfile` mutation (use existing change-stream / Provider listener).
5. In onboarding flow first screen, add a `requestPermissions(alert: true, badge: true, sound: true)` call gated behind a « Voulez-vous être notifié… » CTA (Apple HIG : explanatory pre-prompt before system dialog). Reuse existing onboarding ARB pattern.
6. Wire deep link : when notification is tapped, the existing tap callback receives the payload (already a JSON string). Parse `{intent, prefill}` from payload. Use `GoRouter.of(context).go('/coach/chat?intent=$intent&prefill=$prefill')`.
7. Extend `coach_chat_screen.dart` to read `intent` + `prefill` from `GoRouterState.queryParams` (or constructor args), prefill the input field, emit Sentry breadcrumb `proactive_push.tapped`.
8. Run `flutter analyze`, `flutter test`, golden tests, `validate_arb_parity()`, manual sim test via `idb` (notification simulation).
