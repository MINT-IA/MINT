> Add staging as debug-mode fallback so any future `flutter build ios --debug --simulator` (without `--dart-define=API_BASE_URL`) tombe sur staging au lieu de localhost mort. Anti-régression mécanique pour F-01.1-01 P0.

## Trade-off analysis

**Cost** : debug-build cold-start incurs ~700ms penalty when localhost is unreachable (probe times out before staging fallback kicks in). STAMP-02 cold-launch P50 budget = 2.5s ; 700ms = within ceiling.

**Benefit** : eliminates the « coach erreur de connexion » brand-killer that triggered Phase 01.1 PRE-AUDIT. Mechanical guard ; no future agent / developer can ship a sim QA build that silently targets localhost.

**Alternative considered (rejected)** : reorder candidates so staging is first in debug. Rejected because devs with localhost backend running EXPECT localhost-first behavior (otherwise debug runs hit staging even with local backend up, defeating the dev loop).
