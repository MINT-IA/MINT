## Lessons learned (for Phase 01.4 and beyond)

1. **Subagent surcharge** — Waves 1+2 were over-engineered (8 curl probes + 1 YAML write didn't need Task agents). Sub-phase 01.4 will inline-orchestrate small deterministic tasks ; reserve agents for cross-file deep audit.
2. **Doc ceremony** — CONTEXT + RESEARCH + VALIDATION + OBSERVATIONS + BUG-INVENTORY + LAYER-B-PATCH-DRAFT + SUMMARY = 7 docs for 1 sub-phase. Sub-phase 01.4 will collapse to ONE `01.4-AUDIT.md` with sections.
3. **`.nosync` provenance** — first build failed because I didn't pre-apply `codesign --remove-signature` on `Flutter.framework/Flutter` per `apps/mobile/ios/strip_provenance.sh` doctrine. Memory note added : always run pre-strip before sim builds when working tree is in iCloud Drive `.nosync` mount.
4. **Maestro selector verification** — Wave 2 dry-run via `check-syntax` only validates YAML schema, not runtime selector resolution. Wave 3 ground-truth surfaced 4 selector corrections (Coach tab label, composer hint, citation regex). Sub-phase 01.8 (Maestro grammar refactor) will own this.
5. **Production gap** — `/api/v1/anonymous/chat` 404 on production is intentional per memory `project_no_real_prod_yet`, but the candidate ordering puts production FIRST in release. If we ship to App Store without changing this, the coach won't work on App Store builds either. Strategy decision needed before Phase 01 closes.
