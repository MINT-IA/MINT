## 0. Why this sub-phase exists first

CONTEXT §13 (parent) inverted Q-13 default user-flow ordering into a **PRE-AUDIT** discipline : run the hero flow on a real sim against staging **before** spending mapper effort on assumed code. Reason : memory `feedback_audit_corpus_before_patching.md` + 0-trust §9.5 « PR opened ≠ shipped, tests passing ≠ feature working » — every prior MINT audit that grep'd first and walked-through later ended up patching test theater rather than real blockers. 01.1 closes that loop : the audit grounds in observed reality (Maestro flow output + idb describe-all + Julien observations) before mappers spawn in 01.2.

## 1. Mission (single sentence)

Run the hero flow **onboarding → coach chat that emits ≥1 cited number within 3 turns (hero number = marge fiscale 3a annuelle)** end-to-end on a booted iPhone 17 Pro sim against Railway staging (post-PR #663 icon merge + post-OPENAI_API_KEY + post-pgvector embedding of 103 docs), capture observed blockers with deterministic citation, write `01.1-OBSERVATIONS.md` that becomes the grounded input for sub-phases 01.2 → 01.10.

## 7. Counter-arguments

- **« Why walkthrough first when mappers can grep blockers faster ? »** — grep produces theoretical findings ; sim produces grounded ones. Memory `feedback_audit_corpus_before_patching.md` + Karpathy #1 « state assumptions, surface tradeoffs » + 0-trust §9.5 « PR opened ≠ shipped ». Mapper-first audits have a history of patching test theater on this repo. Rejected.
- **« Why swiss_native only when CONTEXT §4 allows swiss_native_couple too ? »** — couple flow has 2× the state surface (concubinage vs married) and doubles sim crash risk per memory `feedback_sim_crash_mitigation`. Defer to 01.10 full sweep. Resolved.
- **« Why a new Maestro flow when 17 already exist ? »** — the 17 cover navigation + smoke + chat-as-verb assertions, none assert « cited number within 3 turns » end-to-end. The hero flow is the first assertion of the BAR per CONTEXT §1 Q-02. New flow is mission-critical. Resolved.
- **« Why include adversarial probes if optional ? »** — probes that fail early surface coach-runtime suppression bugs (Wave 1c obs #74) that mappers won't catch via static grep. Cheap signal if hero flow finishes < 30 min. Resolved.

- LSFin banned-term fires in response → CRITICAL — escalate to CONTEXT §6 P0-2 (semantic banned-term sweep) ; do NOT continue 01.1 until P0-2 lands.
