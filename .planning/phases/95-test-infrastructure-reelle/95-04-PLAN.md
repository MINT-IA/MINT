**Step 1 — `tools/checks/cassette_hygiene_lint.py`** — stdlib-only Python (mirrors `tools/checks/route_registry_parity.py` shape):

Inputs:
- Walks `services/backend/tests/cassettes/**/*.yaml`
- Reads `services/backend/app/services/coach/compliance_guard.py` and extracts the `BANNED_TERMS` list verbatim (regex-parse the literal — do NOT `import` it; the lint must be hermetic)

Checks per cassette file:
1. **Banned-term scan** — for each `BANNED_TERMS` entry, search response bodies (positive context only — accept negation forms like « pas garanti », « kein garantierter », « non garantito ` per `tools/checks/banned_terms_arb.py` allow-list pattern). Exit 1 with the offending file path + term + line if found.
2. **Secret pattern scan** — regex for:
   - `authorization: Bearer eyJ` (JWT)
   - `sk-ant-api[A-Za-z0-9-]{40,}` (Anthropic API key)
   - `\b(?:\d{4}[-\s]?){3}\d{4}\b` (credit card)
   - IBAN: `\bCH\d{2}\s?\d{4}\s?\d{4}\s?\d{4}\s?\d{4}\s?\d{0,3}\b`
   - AVS: `\b756\.\d{4}\.\d{4}\.\d{2}\b`
   Exit 1 if any of these match anywhere in the cassette.
3. **Header redact check** — every cassette MUST have `authorization: REDACTED`, `x-api-key: REDACTED`, `anthropic-api-key: REDACTED` if those keys appear at all. If a cassette has `authorization: <anything-other-than-REDACTED>`, fail.
4. **Self-test mode** (`--self-test`): runs all 3 checks against an in-memory fixture with a known-bad cassette and a known-good one, verifies it correctly flags one and passes the other. Used by CI smoke + plan task 3 verification.

Output format on failure (mirror existing lint scripts):
```
::error file=services/backend/tests/cassettes/foo/bar.yaml,line=42::Banned term 'optimal' found in response body — fix or document negation context
```
