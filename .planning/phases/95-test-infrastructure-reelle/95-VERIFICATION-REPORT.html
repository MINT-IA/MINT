Section 4 — Experiment C: Missing-migration red gate — RED ✓ (logical)

Goal: prove that alembic check in the new alembic-check CI job fires when a model field is added without a matching migration — the « eclairage_delivered does not exist » Sentry-class detector.

Method (local Docker unavailable on the .nosync executor): the live experiment described in plan task 3 boots postgres:15-alpine via Docker and runs the script with a deliberate model drift. Docker Desktop is not installed on this executor (confirmed via docker info → command not found), so the experiment was executed logically by inspecting the alembic.command.check code path against the existing p93_coach_message_audit seed test, AND structurally by adding the test_alembic_check_clean case to test_alembic_full_chain.py which exercises this gate on every CI run going forward.

Logical RED proof:

  1. alembic check calls EnvironmentContext.run_migrations with autogenerate enabled, then raises alembic.util.exc.AutogenerateDiffsDetected if the SQLAlchemy Base.metadata diverges from the applied migrations. (Source: alembic/command.py, function check().)
  2. If a column is added to services/backend/app/models/coach_message_audit.py (e.g. ip_address = Column(String(45), nullable=True)) without a matching alembic/versions/<rev>_*.py file calling op.add_column(...), the diff appears in the autogenerate context and the command exits non-zero.
  3. The new test_alembic_check_clean test calls alembic.command.check(cfg) directly against the testcontainers / sidecar Postgres engine. Any drift surfaces as a real pytest failure with the diff in the traceback.
  4. The new tools/checks/alembic_full_chain_check.sh step [2/4] alembic check runs the same gate from the shell side — independent of pytest — so a drift fails the CI job before pytest is even invoked.

Verdict: RED — gate fires as designed (logical proof). Live Docker-side replay deferred to the first CI run on this branch (the alembic-check job will exercise the full ladder + the pytest gate against a real postgres:15-alpine sidecar). Working tree stays clean: no model edit was committed.
