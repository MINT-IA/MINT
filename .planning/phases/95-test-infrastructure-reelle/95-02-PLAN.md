| Mobile test → committed pact files | Test output is committed to repo; tampering risk on contributor side |
| Backend verifier → FastAPI TestClient | Pact verifier proxies HTTP into in-process app; provider-state handlers seed DB |
| CI runner → pact files in repo | Pact-verify job reads committed pacts; regression silent if drift gate misfires |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-95-02-01 | Tampering | Pact author edits both consumer test + pact file inconsistently | mitigate | Drift gate (`git diff --exit-code .planning/contracts/pacts/`) catches mismatch on the next run; mobile must regenerate |
| T-95-02-02 | Information Disclosure | Pact files contain real session IDs / PII captured during test | mitigate | Pact tests use `Matchers.uuid()` / `Matchers.like()` (type matchers), not literal values; reviewer-checked at PR time |
| T-95-02-03 | Tampering | Provider-state handler seeds incorrect data, masking real contract violation | mitigate | Provider-state handlers reuse existing test fixtures (`_fake_user`, `client`); state-handler diff lands in same PR as pact change |
| T-95-02-04 | Denial of Service | Pact verifier hangs on misconfigured provider | accept | `pytest -x` time-out + CI 60-min job time-out cover this; low-frequency event |
</threat_model>
