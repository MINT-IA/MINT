# Summary

The expert panel converged on a stronger product definition:

Mint is a living Swiss financial lucidity dossier, not a chat product. The first experience should produce a visible `Premier éclairage` before account creation, then invite the user to save or continue. The daily product should be a small set of high-trust surfaces, with the coach as a contextual layer.

The recommended engineering path is not a full rewrite. It is a targeted refondation of the state spine, profile write model, account/cloud/reset states, calculation ownership, route/flag governance, and trust grammar.

Current onboarding/auth/reset/restore work remains relevant, but it should be treated as one slice of the larger North Star. The first implementation slices now extend the existing state spine, expose account/data state, and make the `/onb` terminal step show a visible dossier state before the user chooses to continue or leave.
