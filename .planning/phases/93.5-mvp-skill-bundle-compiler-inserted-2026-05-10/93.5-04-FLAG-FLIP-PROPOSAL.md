**Target value :** prod = `true` (post-flip), staging = `true` (unchanged)

## Recommendation summary

**PARTIAL — keep staging ON, defer prod flip until eval-pack methodology is upgraded.**

Two of the three measurable gates do not meet threshold on the existing eval pack. The bundle path scores HIGHER than legacy on overall pass rate (15/50 vs 12/50) and DOMINATES on `brand_voice` category (4/13 vs 0/13), so there is no behavioural regression argument for rolling back staging. But neither path reaches the ≥95% Stage 3 target on this fixture set (legacy baseline is 24%, not the ≥85% Plan 93.5-04 assumed), and the cost-regression test cannot fire because fixtures lack intent labels. Flipping prod now would be flying blind.

## Findings that inform the recommendation

1. **Bundle path beats legacy on the live pack.** 15/50 vs 12/50 (+25% relative) for `all_three_pass`. `brand_voice` category : 4/13 vs 0/13 (Wave 2 fattening landed). `doctrine_pass` : 18/50 vs 14/50 (+28.6%).
2. **Bundle path costs slightly more on this pack, NOT less.** +7.4% prompt tokens, +8.0% latency. Root cause : the 50 fixtures don't carry `intents:` labels, so D-14 routes to always-on path (`compliance-narrator + life-event-router`), and the 11 appendix blocks added by `_build_prompt` dominate the prompt size in both paths. The −40% target is structurally unreachable on this fixture set.
3. **8 regressions on `anti_extractor_leak` compliance L-stack.** Bundle response sentences trip ComplianceGuard L1/L2 at higher rate than legacy. Worth investigating in Wave 4 if flag-flip is approved (could indicate a real, fixable regression OR an artefact of slightly different output cadence — undetermined from the eval data alone).
4. **Eval scorer cannot distinguish meta-quoted banned terms.** `tools/eval_narrator.py:_score_banned_terms` regex matches « 'sans risque' n'existe pas » as a violation, even though the bundle is correctly explaining the LSFin rule. This affects both runs equally (`fix-03..fix-10` all FAIL on both paths), so it does not skew the bundle vs legacy comparison.
5. **Staging soak is provisioned but has not collected data yet.** 48h wall-clock window opens 2026-05-12T15:38:24Z. Sentry pull is a follow-up.
