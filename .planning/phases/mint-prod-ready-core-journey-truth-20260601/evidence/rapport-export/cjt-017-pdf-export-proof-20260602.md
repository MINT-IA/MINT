# CJT-017 — Rapport PDF export proof

Date: 2026-06-02  
Status: verified locally before push  
Scope: `PdfService.generateFinancialReportPdf`

## Finding

The existing PDF service test suite only checked service shape and model construction. It did not execute `generateFinancialReportPdf`, so the salvage trail had no proof that a financial report could be converted into PDF bytes and handed to the platform export layer.

## Fix

- Added a Flutter test with a fake `PrintingPlatform`.
- The test calls the real `PdfService.generateFinancialReportPdf`.
- It asserts one `sharePdf` call, filename `mint_report_v2.pdf`, generated bytes larger than 1 KB, and PDF header `%PDF-`.
- Added bundled Lato TTF assets for PDF generation because the first runtime proof exposed `Helvetica` / missing glyph warnings for typographic French PDF text.
- `PdfService` now builds session, financial, and decision PDFs with the same embedded PDF theme, avoiding runtime font fetches.

## Commands

```bash
cd apps/mobile
flutter test test/services/pdf_service_test.dart --plain-name "generateFinancialReportPdf shares a concrete PDF document"
flutter test test/services/pdf_service_test.dart
flutter analyze lib/services/pdf_service.dart test/services/pdf_service_test.dart
```

## Results

- Focused export proof: passed.
- Full PDF service test file: `16 passed`.
- Analyzer: `No issues found!`.
- The final focused proof output no longer prints missing-glyph or Helvetica Unicode warnings.
