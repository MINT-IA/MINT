## What the change does

Adds an optional `actionSemanticsIdentifier` to `MintConfidenceNotice`, wraps the *inner* CTA (`GestureDetector`) in `Semantics(identifier:, button: true)`, and wires the mortgage affordability screen to pass the stable id `mortgage_enrich_profile_cta`. A new widget/source test is added.

## Wiring verification (facade check)

The identifier is attached to the **real actionable element**, not a decorative wrapper:

- `mint_confidence_notice.dart:92-95` — `Semantics(identifier: actionSemanticsIdentifier, button: true)` wraps exactly the `GestureDetector` carrying `onTap`.
- `affordability_screen.dart:280,284` — same widget keeps `Key('mortgage_enrich_profile_cta')` and now also passes `actionSemanticsIdentifier: 'mortgage_enrich_profile_cta'`.

This completes previously-dangling wiring. The Maestro companion flow `apps/mobile/.maestro/g1_return01_housing_cancel_return.yaml:28,31,36` drives the CTA via `id: "mortgage_enrich_profile_cta"`. A Flutter `Key` is **not** exposed as an accessibility identifier, so before this diff Maestro's `tapOn: id` could not resolve that node; the new `Semantics(identifier:)` is exactly what makes that black-box flow tappable. Wiring is real, not a facade.
