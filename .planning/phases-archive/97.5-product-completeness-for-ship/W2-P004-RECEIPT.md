## Deviations and data gaps

### Data gaps surfaced

1. **`metaphors.toml` has 8 entries, not 96.** Per file header line 1-13 : « 8 entries × 3 archetypes × 2 cantons × 2 life events. Expansion to full archetype × canton × life_event matrix is deferred to a post-v2.9 content sprint (D-19, Karpathy #2 simplicity-first). » Coverage today : `housing` (4 entries) + `family` (4 entries). HOOK_FALLBACK degradation handles every gap including the metaphor-absent case (the `metaphor` slot renders empty string, `NarrativeSleeveCard` hides the block). This is the expected Option A behaviour per W1-T1 ADR §Data-gaps bullet 1.
2. **`metaphors.toml` carries only the `metaphor` field, not `hook_template` / `caption` / `next_step` fields** as the user prompt suggested. The Option A implementation builds those slots from ARB resources + `widget.sourceCard.computedFacts`, not from TOML. This is the simpler design and matches the existing `MetaphorLookup.lookup(...)` API contract.
3. **`MetaphorLookup` is not pre-loaded in the widget test harness.** The new test seeds it via `MetaphorLookup.debugSetLoaded(...)` in `setUpAll`. In production the loader runs in `apps/mobile/lib/main.dart` at app boot (per `metaphor_lookup.dart` line 39-43 docs). The test does NOT cover that wiring — that's the integration-test layer per `metaphor_lookup_test.dart` line 152-179 precedent.
