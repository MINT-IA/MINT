- **Playwright behind `[oracle]` extra, not `[dev]`** — keeps default backend dev install lean ; matches CONTEXT D-11 « manual annual cadence » framing.
- **Fixture EMPTY on first commit** — strict 0-trust §9 application : we ship the matcher + the lint + the scraper, but do NOT pre-populate `expected_tax_chf`. - **`pytest.mark.parametrize("idx", range(50))` fixed at 50** — stable suite shape across captures (CONTEXT D-12 locks 50 exact). Under-populated fixtures cleanly skip beyond their length.
- **Capital tax surrogate for income vectors** — documented in `_mint_capital_tax_for` docstring : the 50-vector matrix in D-12 mixes income/capital cases ; first Julien capture will reveal the real ESTV result-panel structure ; until then, vectors are treated as capital-withdrawal stand-ins. Income-tax matcher composition with `cantonal_comparator.py` is OUT-OF-SCOPE for this MVP scaffold per plan note line 400.
- **JSON parse error = hard fail (exit 1) even without `--strict`** — diverges slightly from « WARN-only » framing but is the correct correctness boundary : a malformed fixture means the lint cannot honestly answer the freshness question. Stale-but-parseable stays WARN-only.
