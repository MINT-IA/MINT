3. Classes de fabrication découvertes (front-loadées entre écrans)

La revue adversariale Codex a cristallisé ~9 classes, front-loadées dans les specs suivantes (divorce 8 rounds → gender_gap 2 rounds) :

  • Défauts de champ (90k revenu, 200k fortune) → nullable + « Non renseigné » + gate par sortie.
  • Widgets secondaires à taux codé en dur (PrixDuSilence fortune×24 %, film 1500/enfant) → retirer / consommer la vraie valeur service.
  • Constantes service codées en dur (canton='ZH') → threader le canton réel + gate.
  • Bypass chaîne/enum (canton ''/'XX'/fromJson ?? 'ZH') → clé fournie ∧ code valide (26).
  • Recompute divergent (film recalculait le transfert LPP en total-balance) → consommer la valeur service.
  • Énoncés présumant une circonstance non confirmée (direction, garde, testament) → conditionnel.
  • Agrégat attribué à l'individu (delta fiscal C1+C2 = « tu perds ») → « le ménage ».
  • Préconditions légales domaine (concubin héritier, éligibilité survivant art. 19, réserve héréditaire) → cadre conditionnel + ordre légal.
  • Hypothèses de modèle divulguées (taux effectif 0.65, rendement 1.5 %, durée 20 ans) → PAS gate-dur : divulguer + bead fiscal.
