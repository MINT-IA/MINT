Section 5 — Local-sim env limitation discovered

Attempted a local feasibility run of walker_audit_tap_render.sh --no-dry-run --archetype swiss_native --tab drawer on the Mac mini. Build failed at debug_unpack_ios:

Failed to codesign /Users/.../Flutter.framework/Flutter with identity -
resource fork, Finder information, or similar detritus not allowed

Root cause: macOS Tahoe + the ~/Desktop/MINT.nosync/ directory attaches a com.apple.provenance xattr to every file built inside it (iCloud Drive opt-out marker). Xcode's « Strip xattrs before codesign » build phase doesn't catch the Flutter framework xattr in time. xattr -cr only clears most xattrs; com.apple.provenance is sticky and re-attaches on every new file.

Workaround: walker_nightly.yml on macos-latest CI (no .nosync directory, no provenance xattr) is the correct execution path. Local feasibility runs not supported until either the repo is moved out of ~/Desktop/MINT.nosync/ or a pre-build xattr-strip script is added (Phase 54.x candidate).
