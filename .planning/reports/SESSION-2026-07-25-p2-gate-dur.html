2. Modèle de provenance (state-machine)

stateDiagram-v2
  [*] --> Assumed : défaut fabriqué
  Assumed --> SeededFromProfile : userProvidedFields contient la clé (à chaque notify)
  Assumed --> Touched : l'utilisateur édite le contrôle
  SeededFromProfile --> Assumed : profil perd la clé / clear (re-évalué)
  SeededFromProfile --> Touched : l'utilisateur édite (touched supersede seed)
  Touched --> Touched : reste user-owned (immunisé au clear)
  SeededFromProfile --> Confirmed : gate ouvre
  Touched --> Confirmed : gate ouvre
  Confirmed --> Assumed : valeur consommée change -> _result invalidé
  note right of Confirmed : Le chiffre ne rend QUE si\ntous les faits déterminants\nde cet output sont Confirmed
