# MINT Financial Calculation Contract

Require inputs, units, assumptions, authority date, formula version, missing
facts, confidence/range, and golden cases. The displayed value, handoff, coach
claim, and receipt must use the same calculation output. Reject LLM-generated
numbers, silent defaults, non-finite values, and duplicate engines.
