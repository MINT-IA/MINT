# MINT Consent and Provenance

For each fact record provider/document, source identifier, observed-at time,
validity, purpose, consent receipt, extraction confidence, corrections, and
calculations consuming it. Prove revoke, export, delete, and conflicting-source
reconciliation. An API success response alone is not proof of current truth.
