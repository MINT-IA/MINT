# MINT Journey Design

Specify persona, trigger, promise, first value, one primary action, success
proof, required facts, missing-data behavior, exits, regulatory boundary, and
runtime path. Reject feature lists and screen inventories without a decision
spine. Test the prototype with users before promoting it to implementation.
