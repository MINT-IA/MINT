# MINT Next — Batch 3

Batch 3 is a derivative, local comparison prototype. It replays the three
promoted Batch 1 mechanisms with one identical promoted Batch 2 Vaud fixture.
It does not rewrite Batch 1 or Batch 2 history.

The prototype consumes a static audited receipt. It does not call a tax engine,
the Vaud form, an LLM, or a product API. Any edited tax assumption invalidates
the displayed CHF 2’104 result; this prototype deliberately cannot recalculate.

No direction is selected. No moderated participant has used Batch 3. Flutter,
production, nationwide tax coverage and financial advice remain out of scope.
