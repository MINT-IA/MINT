# MINT Next — Batch 1 design experiment

Batch 1 compares three interaction models for the same Swiss tax-first task.
It is not a Flutter implementation and does not claim user validation.

The source matrix deliberately separates governing rules, bounded inspiration,
and excluded duplicates. All three prototypes must use the same persona, facts,
calculation output and evaluation tasks so visual finish cannot manufacture a
winner.

Current status: `draft_unproven`.
